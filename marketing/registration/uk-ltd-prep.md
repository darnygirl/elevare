## Why UK Ltd (bridge)

```
✓ £12-50 total (cheapest credible jurisdiction)
✓ 24-48hr formation via Companies House online
✓ Solo director allowed (Debby, no Donal needed)
✓ Companies House = recognised by every procurement team globally
✓ Compatible with Wise / Revolut / Stripe
✗ Non-EU post-Brexit — long-term we want Estonia OÜ instead
✗ Annual return + accounts filing each year
```

**Strategy:** UK Ltd buys time. Estonia OÜ via e-Residency is the
proper long-term home (EU presence, low admin, fully digital).
File UK Ltd when the first contract demands it; let Estonia
catch up in parallel.

## When to actually file

Trigger conditions (any one of these → file the same week):

```
1. First B2B contract requires a registered entity number
2. Stripe / Wise Business asks for company registration
3. First $500+ in revenue accumulates and needs a clean
   business-account home (not personal account)
4. Estonia e-Residency application gets rejected or stalls
   past 3 months — UK becomes the long-term entity by default
```

Until then: Debby can invoice as a sole trader (Thai address,
informal). Most early customers won't ask. The hospital that
DID ask just declined for unrelated reasons.

## Estonia OÜ (parallel long-term track)

Run in parallel with UK Ltd, NOT instead. Reasons:

```
✓ EU jurisdiction post-incorporation
✓ Fully digital admin (e-Residency card runs the whole company
  remotely — file taxes, sign docs, manage bank from anywhere)
✓ 0% corporate tax on retained profits (only pay on distributions)
✓ Best-in-class for digital-first founders living nomadically
✗ €100 e-Residency application + €265 OÜ formation = ~€365 upfront
✗ 4-8 weeks (e-Residency card mailed to a pickup point)
✗ Annual fee for accounting service (~€50-100/mo)
```

Trigger to start Estonia application: when UK Ltd is filed AND
first €500 has accumulated. Don't burn cash on Estonia before UK
Ltd is in place — the order matters because UK Ltd is the bridge
that lets Estonia run without urgency.
