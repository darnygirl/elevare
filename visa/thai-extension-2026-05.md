## Common rejection reasons (avoid these)

```
1. NO TM.30 ON FILE                  ← MOST COMMON
   Landlord must have filed Debby's address with immigration.
   Without it, extension can be refused or delayed.
   FIX: call landlord Sunday, confirm TM.30 done. If not,
   landlord can file online same-day at immigration.go.th.

2. PHOTOS WRONG SIZE / BACKGROUND
   White background only. 4x6 cm. Passport-style.
   FIX: redo photos at the photo shop near immigration
   (~150 THB). Don't try to argue.

3. PHOTOCOPIES NOT SIGNED
   Each photocopy needs a BLUE-ink signature at the bottom.
   FIX: bring a blue pen, sign on-site if needed.

4. PASSPORT VALIDITY < 6 MONTHS
   Thailand requires passport valid 6+ months past visa expiry.
   Debby's passport: check expiry date BEFORE Monday.
   If <6 months from June 10 → blocked. Need new passport
   from Ugandan embassy first (Bangkok). Days/weeks process.

5. CASH SHORT
   Bring at least 2,400 THB total (1,900 fee + 500 buffer).

6. WRONG INTENDED DEPARTURE DATE
   Write a date that is BEFORE the stamp expires (i.e. before
   ~June 10). They want to see you have a plan to leave.
```

    paperwork.
